# Monk Lang

A minimalist, readable, and performant programming language for the modern age.

**Performance** of compiled languages. **Simplicity** of Python. **Memory safety** inspired by Rust.

> This is a ground-up rewrite. The original implementation (TypeScript/Bun tree-walking interpreter) is archived at [monk-lang-v1](https://github.com/monkfromearth/monk-lang-v1).

## Status

Starting fresh. Implementation language TBD.

## Structure

```
spec/       — Language specification
tests/      — Test suite (contract for the implementation)
examples/   — Example programs
docs/       — Guides and tutorials
src/        — Implementation (TBD)
editor/     — VS Code extension, LSP
scripts/    — Build and automation scripts
```
