No emojis in knowledge/ HTML pages. Use inline SVGs or icon libraries instead.
No purple, violet, or indigo colors anywhere in the palette.
Avoid horizontal scrollbars — make pipeline diagrams responsive or wrap.

**Why:** Emojis look unprofessional and inconsistent across platforms. Purple is not in the brand palette. Overflow creates bad UX.
**How to apply:** Every knowledge/ page. Use warm palette (orange accent, blue, green, amber, stone). SVG icons for pipeline steps.
